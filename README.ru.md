# xbsl-en-skills

[English](README.md) · Русский

Скиллы Claude Code / агентов **для проектов 1С:Предприятие.Элемент (xBSL)**, у которых
язык разработки — **английский** (`DevelopmentLanguage: English`).

Большинство существующих наборов скиллов под Элемент генерируют русские ключевые слова
и русские имена (`Процедура`, `ФормаОбъекта`, `ВычислитьРазрешенияДоступа`). Эти скиллы —
наоборот: каждое ключевое слово, имя типа и идентификатор **по умолчанию английские**
(`method`, `val`, `throw`, `StandardTableColumn`, `Colors.Red`, …), под проект,
сконфигурированный с английским языком разработки.

Каждый паттерн здесь написан для реального продакшн-приложения Элемент (платформа 9.2, затем 10.0) и **проверен
деплоем** в него, а не реконструирован по документации.

## Скиллы

| Скилл | Что делает |
|-------|------------|
| [`xbsl-en-deploy`](xbsl-en-deploy/) | Clean-room руководство по деплою проекта Элемента в облако (1cmycloud) через Console API: собрать `.xasm`, загрузить, переключить приложение на новую сборку, дождаться `Running`. Описывает API и практические подводные камни; скрипт сборки — свой. |

## Установка

Скопируйте (или сделайте симлинк) папки скиллов в каталог скиллов Claude Code:

```bash
# для конкретного проекта
cp -r xbsl-en-deploy  /path/to/project/.claude/skills/

# или глобально для пользователя
cp -r xbsl-en-deploy  ~/.claude/skills/
```

Скилл — это просто папка с файлом `SKILL.md` (YAML-фронтматтер + инструкции) и
опциональными `references/` и `scripts/`. Ничего не компилируется.

## Область применения

- **Цель:** 1С:Предприятие.Элемент (xBSL), платформа 9.2 и 10.0, английский язык разработки.
- **Не** для классической 1С:Предприятие (BSL, `Процедура`/`&НаСервере`/СКД/конфиг-XML).
  Это другой язык и другая платформа.
- Авторитетный источник имён API/типов — документация Элемента. Эти скиллы кодируют
  *паттерны*, а не полный справочник API.
